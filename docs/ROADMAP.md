# FunBytes Product & Technical Roadmap

## Phase 1: Developer Experience MVP (Completed) 🚀
- [x] High-performance Expo React Native app with Dark Mode.
- [x] Topic selector and 3-step onboarding flow.
- [x] Developer feed aggregating `r/developersIndia`, `Medium Tech`, and `DevHumor`.
- [x] Optimistic likes, bookmarks, threaded comments, and native Android sharing.
- [x] Pluggable backend ingestion system with deduplication and ranking.
- [x] 80+ item mock dataset for offline and testing mode.

## Phase 2: Multi-Category Expansion 🎨
- [x] Political Cartoons gallery feed & dedicated meme stream.
- [x] BBC, Al Jazeera, and Press Information Bureau (PIB) integration.
- [x] Advanced search with category filters and trending tags.

## Phase 3: Social & User Customization 🤝
- [ ] User profiles, follow relationships, and personal creator posts.
- [ ] Push notifications for trending topics and comment replies.
- [ ] Community moderation dashboard with report queues.

## Phase 4: AI & Semantic Intelligence 🤖
- [ ] Automated LLM-powered multi-source news synthesis.
- [ ] Semantic deduplication with vector embeddings.
- [ ] Voice byte summaries for on-the-go audio feeds.
